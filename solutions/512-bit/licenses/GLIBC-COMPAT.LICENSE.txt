GNU C Library (glibc) — bundled compatibility header
=====================================================

File: gpu_nfs_siever/compat-include/bits/mathcalls.h

This file is a byte-identical copy of the system glibc header
/usr/include/x86_64-linux-gnu/bits/mathcalls.h with exactly ONE declaration
(the C23 `rsqrt` MATHCALL) commented out, to work around a header clash between
glibc >= 2.41 and the CUDA 13.0 toolkit (see gpu_nfs_siever/compat-include/README
for the full rationale and the one-line regeneration command).
